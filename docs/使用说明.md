# 照片修复

白色极简的照片修复专用本地版，基于 Infinite Canvas v0.20.0 定制。

## 使用方法

1. 按仓库 README 完成依赖安装和构建，在项目根目录运行 `Launch.ps1`，打开 **照片修复**。本机已安装版也可双击原有桌面图标。
2. 第一次使用，点击右上角 **API 设置**，选择 OpenAI／OpenAI 兼容接口或 Google Gemini，填写自己的地址、Key 和支持图片编辑的模型名称。
3. 导入照片，选择 **老照片修复、清晰增强、仅提升清晰度、人像修复、黑白上色** 中的一种，可补充自己的修改要求。
4. 点击 **开始修复**。完成后拖动分界线对比原图与结果，或切换“原图／修复后”。
5. 点击 **保存照片** 导出修复结果。需要进一步修改时可点击“继续精修”。

原图不会被覆盖。

**仅提升清晰度** 会要求模型只改善模糊、噪点和细节，保留原有颜色、色调、白平衡与整体明暗；黑白照片仍保持黑白。此模式下补充要求不会覆盖保色限制。实际结果仍由所选图像模型生成，保存前可与原图对比确认。

对比预览会在本地对原图和修复结果做位置、比例对齐。左右拖动只改变分界线，照片保持固定。此对齐仅影响预览，保存的照片保留 API 返回内容。

## 保存后继续修改

- 当前照片和修复记录自动保存在此浏览器本地。
- **保存项目** 会导出包含原图、结果和修改要求的 `.photo-restore.zip` 文件，不包含 API Key。
- 下次点击右上角 **打开项目**，选择这个文件，即可继续修改。
- 重要项目请导出文件备份；清除浏览器站点数据可能清除本地记录。

## 联机范围

已停用社区／远程提示词库、自动提示词同步、远程插件、WebDAV 同步、Agent、通用视频生成和音频创作、分析统计及更新入口。保留照片修复和新增的视频逐帧修复。

启动、导入、预览、项目保存和本地记录无需连接外部服务。只有点击照片“开始修复”或视频“开始／继续／重试逐帧修复”时，才会连接所选修图 API，并下载其返回的结果。因此修复仍需要联网，费用和效果由所选服务商及模型决定。

## 视频逐帧修复

1. 在照片修复页面右上角点击 **视频修复**，沿用已经配置的图像 API，无需 fal Key。
2. 导入 MP4、MOV、MKV、WebM、M4V 或 AVI。软件先在本机拆帧，不会自动调用收费 API。
3. 默认选择 **仅提升清晰度**，也可以选择其他方式或补充要求。确认页面显示的帧数与预计调用次数后，点击 **开始逐帧修复**。
4. 每一帧依次请求一次图片编辑 API，成功后保存到本机。点击 **本帧完成后暂停** 会等当前帧保存再暂停；关闭或刷新后，可从 **视频记录** 打开并继续，已保存的帧不会重新请求。
5. 全部帧完成后，在本机按原有画面时间合成 MP4，并将原音轨转为 AAC 放入结果。点击 **保存视频** 下载。原视频不会被覆盖。

**调用费用：** 10 秒、30 帧／秒的视频约需 300 次图片编辑调用。费用由所选 API 计算。失败或中断的帧可能已计费，界面会在手动重试前提示；程序不会自动重试收费调用。

**效果与保存：** 逐帧图片模型无法保证时间上的一致性，可能出现细节闪烁，建议先试短视频。仅提升清晰度会要求保持原色，但实际效果取决于所选模型。拆帧、结果和任务记录存放在安装目录的 `video-jobs` 文件夹，文件可能较大，请预留磁盘空间。该目录不保存 API Key。已开始的任务锁定原修复设置；需要改用其他方式时重新导入原视频。

拆帧、合成和本地记录通过本机服务完成。修复时请保持软件页面打开；暂停或刷新后不会自动恢复收费调用。

## 本地启动

源码可放入自己选择的文件夹；视频记录和日志保存在该文件夹内，照片记录与 API 设置保存在当前浏览器站点数据中。

本机页面：[照片修复](http://127.0.0.1:31873/restore)。请先通过 `Launch.ps1` 或已安装版桌面图标启动服务。

旧的 `/canvas`、`/image` 等地址会自动转到照片修复页面。
